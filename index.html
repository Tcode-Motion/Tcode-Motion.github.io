Everything You Need

A full-stack language that handles scripting, web development, and desktop apps — all with plain English syntax.

🦀
Native Rust VM
The core compiler and virtual machine are built in pure Rust. Zero runtime overhead, memory-safe, blazing-fast execution with no garbage collection pauses.
📖
Plain English Syntax
Write make x be 10 instead of let x = 10;. Every keyword was chosen to read like a natural sentence.
🌐
Build Full Websites
Use use web to build complete websites with no HTML, CSS, or JavaScript files. One .txs file, browser opens automatically.
🖥️
Studio IDE Included
TechScript Studio ships with the installer — resizable docking layout, AST inspector, multi-channel terminal, and a cyberpunk dark theme with dragon branding.
📱
Cross-Platform
Windows (native Rust), Linux (Ubuntu/Kali/Arch), macOS, and Android (Termux). Same code, everywhere — no platform-specific rewrites.
🎨
VS Code Extension
Full syntax highlighting, code snippets, and the 🐉 dragon file icon for .txs files. Install from VSIX in one command.
⚡
150+ Built-in Functions
Math, crypto (SHA-256, MD5, Base64), JSON, string ops, OS interaction, random, date/time — all available natively without importing anything.
🔍
AST & Bytecode Inspector
See the live parsed Abstract Syntax Tree and VM execution instructions side-by-side in the Studio IDE. Debug at the deepest level without leaving the IDE.
🔧
Full CLI Toolchain
tech run, tech check, tech repl, tech transpile — every workflow covered from the terminal.

Why TechScript?

See how TechScript stacks up against Python and JavaScript — and why readable code wins.

Feature / Task 🐉 TechScript 🐍 Python 🌐 JavaScript
Print to screen ✓say "Hello!" ~print("Hello!") console.log("Hello!")
Variable ✓ Reads naturallymake x be 10 x = 10 let x = 10;
If condition ✓ Plain Englishwhen age > 18 { ... } if age > 18: if (age > 18) {
Loop ✓each i in 1..10 { ... } for i in range(1,11): for(let i=1;i<=10;i++){
Function ✓build greet(name) { ... } def greet(name): function greet(name) {
Class / OOP ✓model Dog { ... } ✓class Dog: ✓class Dog {
Build a website ✓ 1 file, no HTML/CSSuse web
make page = WebPage("App")
page.run()		 ~ Flask/Django needed ~ Node/Express needed
Error handling ✓attempt { ... } catch err { ... } try: ... except Exception as e: try { } catch(e) { }
Native VM / Speed ✓ Pure Rust VM ✗ Interpreted ~ JIT (V8)
Bundled Studio IDE ✓ Ships with installer ✗ External tools ✗ External tools
Semicolons required ✗ None needed ✗ None needed ✓ Required
Beginner friendly ✓ Highest — reads like English ~ Good ✗ Complex syntax

🐉 TechScript

// Fibonacci in TechScript
build fib(n) {
  when n <= 1 { give n }
  give fib(n-1) + fib(n-2)
}
say fib(10)

🐍 Python

# Fibonacci in Python
def fib(n):
  if n <= 1:
    return n
  return fib(n-1) + fib(n-2)
print(fib(10))

🌐 JavaScript

// Fibonacci in JavaScript
function fib(n) {'{'}
  if (n <= 1) return n;
  return fib(n-1) + fib(n-2);
{'}'}
console.log(fib(10));

Quick Contribution Guide

01

Fork the repository

Click Fork on GitHub to get your own copy of TechScript.

gh repo fork Tcode-Motion/techscript
02

Clone locally

Pull your fork to your machine and create a feature branch.

git clone https://github.com/YOUR_USERNAME/techscript.git
03

Make your changes

Add features, fix bugs, improve docs — anything helps. Test with tech run.

tech run examples/hello.txs
04

Push and open a PR

Push your branch and open a Pull Request. Describe what you changed and why.

git push origin your-feature-branch

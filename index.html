🐉 TechScript

            
// Fibonacci recursion
build fib(n) {
  when n <= 1 { give n }
  give fib(n-1) + fib(n-2)
}
say fib(10) // 55

          


          

            
🐍 Python

            
# Fibonacci recursion
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

print(fib(10)) # 55

          


          

            
🌐 JavaScript

            
// Fibonacci recursion
function fib(n) {
  if (n <= 1) return n;
  return fib(n-1) + fib(n-2);
}

console.log(fib(10)); // 55

Under the Hood: Pure Rust VM

          
TechScript converts plain English source text into compiled bytecode designed for VM execution.

Developer writes plain-text instructions in a .txs extension script.

          

          →

Lexer & Parser

            
Characters form tokens. The parser creates an Abstract Syntax Tree (AST).

          

          →

          

            
3

            
Bytecode

            
TechScript compiler translates AST structures into binary instructions.

          

          →

          

            
4

            
Rust VM

Frequently Asked Questions

          
Answers to common questions about compiling and deploying TechScript scripts.

        


        

          

            
            

              TechScript is an open-source programming language that lets you write code using plain English sentences. Keywords are selected to match conversational words like say, make, when, and build, allowing absolute beginners to understand programs immediately. It compiles to bytecode run on a fast Rust Virtual Machine.
            

          


          

            
            

              TechScript compiles source code into custom binary bytecode. This bytecode is then loaded and executed by the TechScript VM, which is written in Rust. Additionally, developers can transpile TechScript directly into Python files using the CLI toolchain: tech transpile file.txs.
            

          


          

            
            

              TechScript Studio is the official desktop IDE for TechScript developers, bundled in our Windows installer. It provides coding terminals, a file tree editor, a debugger inspector, and visual displays of the parsed Abstract Syntax Tree (AST) alongside compilation bytecode.
            

          


          

            
            

              Importing 'use web' allows you to create WebPage layout instances. You can define heading nodes, paragraph sections, form inputs, and styles inside your .txs code directly. Running the script launches a local HTTP server and renders the HTML, CSS, and JS components dynamically in the browser.

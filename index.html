Code That Reads Like a Sentence

Every TechScript keyword was chosen to sound natural in English. If you can read, you can read TechScript.

Print to screen
You want to say something →
say "Hello, World!"
Create a variable
You want to make something →
make score be 100
Constant (never changes)
You want to keep something →
keep PI be 3.14159
Conditional logic
Something happens when true →
when age >= 18 { ... }
Loop / repeat
Do something for each item →
each i in 1..10 { ... }
Function / reusable block
You want to build something →
build greet(name) { ... }
Return a value
Give something back →
give result
Class / object model
Model a real-world thing →
model Dog { ... }
Error handling
Attempt something safely →
attempt { ... } catch err { ... }

🐉 TechScript

// Reads like English
build fib(n) {
  when n <= 1 { give n }
  give fib(n-1) + fib(n-2)
}
say fib(10) // 55

🐍 Python

# Python recursion
def fib(n):
  if n <= 1:
    return n
  return fib(n-1) + fib(n-2)
print(fib(10)) # 55

🌐 JavaScript

// JS recursion
function fib(n) {'{'}
  if (n <= 1) return n;
  return fib(n-1)+fib(n-2);
{'}'}
console.log(fib(10)); // 55

TechScript 2.0 Roadmap

Tracing the evolution from plain-English scripting engine to a fully optimized compiled ecosystem.

✓ Completed

Phase 1: Core Engine

  • Lexer — Natural keywords parsing engine
  • Parser — Abstract syntax validation
  • AST Generation — Deep syntax tree hierarchy
  • Virtual Machine (VM) — Blazing-fast native execution
  • Bytecode Compiler — Custom bytecode instruction set
⚡ In Progress

Phase 2: Tooling & UX

  • CLI Toolchain — Compiling and REPL runtimes
  • Standard Library — 150+ robust built-in mathematical & cryptographic functions
  • Package Manager — Native module imports and repository package sharing
🚀 Next Horizon

Phase 3: TechScript 2.0

  • LLVM Compiler Backend — Direct compilation to highly optimized machine code
  • JIT Compiler — Runtime compilation for high-frequency loops
  • Visual Debugger — Full IDE debugger interface with stack trace
  • Language Server Protocol (LSP) — Smart auto-complete and diagnostics for code editors
  • Incremental Compilation — Build cached modules in milliseconds
  • TechScript Studio IDE — Cross-platform desktop interface expansions

Frequently Asked Questions

Everything about TechScript — the world's most readable programming language.

TechScript is an open-source programming language where you write code using plain English words. Instead of cryptic symbols, you use say (print), make (variable), when (if), each (loop), and build (function). It runs on a native Rust virtual machine and is completely free and open source under the MIT license.
TechScript is designed from the ground up to be the most beginner-friendly programming language available. Its syntax reads exactly like an English sentence — making it ideal for absolute beginners, students, children, and anyone who finds traditional programming syntax confusing. There are no semicolons, no complex bracket structures required, and every keyword was chosen to be immediately understandable in plain English.

The CLI can be installed via pip install techscript-lang on any platform that runs Python 3.10+. There are no official Linux or macOS native installers at this time.

It features a resizable docking layout (powered by egui_dock), a code editor with line numbers, a workspace file explorer, a multi-channel terminal (separate tabs for stdout, compiler output, and VM debugger), and an AST & Bytecode Inspector. TechScript ships with a bundled IDE and can transpile to Python via tech transpile. TechScript also runs on a native Rust VM rather than Python's interpreted CPython engine.
